# 03 电商漏斗 · 你要收集什么

> 对应网站项目：`ecommerce-funnel-analysis`  
> **性质**：个人练习 · 公开数据 · 投 **电商类** JD 时用。

## 放进本文件夹

| 放 `raw/` | 放 `screenshots/` |
|-----------|-------------------|
| 数据集文件或下载链接.txt | 漏斗 **主图 PNG** |
| `.ipynb` 或 `.py` 分析脚本 | 渠道下钻图 |
| 清洗后 CSV | 结论摘要（3 句话） |

## 必须搞清

- [ ] 数据集名 + 链接（Kaggle 等，确认许可证）
- [ ] 四步漏斗 **真实转化率**（填数字）
- [ ] 选 1 个下钻维度（渠道/设备等）
- [ ] 是否 **写进简历**（投电商岗建议加一行）
