# 数据分析岗位与看板价值（知识补充）

> **总结**：你做的 Tableau 看板 ≈ 岗位交付形态的 **入门展示**，不是岗位的全部。  
> **不必背全文**；被问「分析有什么价值 / 是不是太简单 / 小公司要不要」→ 打开本节，背 **`00-纯记忆版`** 里对应 20 秒段即可。

---

## 1. 看板目的 ≠ 整个数据分析

| 你刚练的 | 岗位里还有 |
|----------|------------|
| KPI、Top 词、趋势、渠道、散点 | 口径对齐、埋点/日志理解、异常排查 |
| Tableau 一屏展示 | SQL 取数、清洗、周报文字结论 |
| 练习 CSV / Public 链接 | 内网脱敏、和业务方开会 |

**面试怎么说：**  
「Public 看板演示的是 **交付长什么样**；实习价值在 **指标定义、异常发现和周报建议**，不是图有多炫。」

---

## 2. 分析结果给谁用、干什么

**背景：** 招投标搜索上线后，运营/产品不能凭感觉改热词和结果页。

| 交付 | 频率 | 用途 |
|------|------|------|
| Tableau 看板 | 周更 | KPI、热词、趋势、渠道一屏看 |
| 周度简报 | 每周 | 2～3 条「发现—原因—建议」 |
| 临时 SQL | 按需 | 某词/某渠道异常时拉数 |

**四类用途（口述用）：**

1. **热词与内容** — 搜索高的词 → 专题、联想词、首页推荐  
2. **结果页质量** — 高搜低点击 → 摘要、排序、详情量  
3. **渠道与端** — 某渠道跳出高 → 落地页、移动端列表  
4. **排优先级** — 异常进下周待办，不堆数字

---

## 3. 为什么看起来「简单」还有价值

- **简单的是展示层**；难在问对问题、口径一致、结论能行动。  
- **AI 时代**：算数、出图更快；仍要人定 **算什么、信不信、给谁看、改完怎么验**。  
- **应届作品集**：证明走过 **取数→指标→可视化→结论** 链路，比空口「我会分析」可信。

---

## 4. 小公司要不要数据分析岗

| 情况 | 说明 |
|------|------|
| 常不单独招「纯分析师」 | 运营/产品/开发 **兼看数** |
| 不是「没必要看数」 | 是谁来 **解释数、写建议** 的问题 |
| 更贴你的表述 | **用数据支撑产品和运营**，AI 提效；Tableau/Excel 是工具 |

投 **小公司**：强调能落地、能沟通、开发+分析同一业务。  
投 **数据岗**：强调方法论 + Public 链接 + 实习叙事。

---

## 5. 和 AI 的关系（一句）

「分析过程可以用 AI 辅助 SQL 和探索；**口径、业务问题和周报结论** 是我负责的；看板是给非技术同事看的界面。」
