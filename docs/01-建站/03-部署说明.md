# 部署（改名后重部署）

> 你已经上过线。平时改内容 = `git push`，等 Cloudflare 自动构建。

---

## 改名 / 换正式地址（常用）

1. Cloudflare Pages 项目名或自定义域名按你需要改好，记下正式 `https://….pages.dev`（或自有域名）  
2. 改 `astro.config.mjs` 里 `site: 'https://…'`  
3. 改 `public/robots.txt` 里 Sitemap 同一域名  
4. 本地：

```powershell
cd "d:\AAA project\Personal Website"
git add .
git commit -m "chore: update site URL"
git push
```

5. 等构建成功 → 手机流量打开：首页 / 三项目 / 关于 / 简历
6. 简历写完整 `https://` 链接

换简历 PDF：覆盖 `public/files/resume.pdf` → push。

---

## 第一次部署（新环境才看）

1. GitHub 建空仓库 → 本机 `git remote` + `push`  
2. Cloudflare → Workers & Pages → Connect Git → 选仓库  
3. Build：`npm run build` · 输出：`dist` · 环境变量 `NODE_VERSION=22`  
4. Deploy → 得到 `*.pages.dev`

备选：Netlify / Vercel（同样 `npm run build` → `dist`）。

**维护：** 平常零维护；免费静态站访问量远超海投。卡住把构建日志原文留下即可。
