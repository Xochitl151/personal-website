# 个人网站需求（简版）

> **给谁看**：面试官 / HR，**补充简历**（过程、思考、图），不是把 PDF 再贴一遍。  
> **投什么岗（主线）**：数据分析 + AI 产品 / 应用（含运营、助理、应用开发类 JD）。  
> **副线**：实习 Web（Cursor/AI 辅助开发，投应用开发时用）。**测试/评测项目页、Power BI 同题、电商漏斗作品 → 不做。**  
> **能力垫（一句带过）**：PS、剪辑、学得快 → 证明交付不丑，不当单独主业。

---

## 要达成什么

| 目标 | 说明 |
|------|------|
| 一眼有用 | 半分钟内：你是谁、作品在哪。 |
| 有设计感 | **浅色站**；图、版式、留白带着读，信息仍好找。 |
| 少维护 | 内容以 Markdown 为主；**Git → Cloudflare Pages / Netlify**，`git push` 更新。 |
| 能扩展 | 需要时加 `/pitch/data`、`/pitch/ai` 等固定页；远期再考虑 AI 匹配器。 |

**不做**：登录、评论、支付、重 CMS、首屏大视频炫技。

**红线**：与简历一致，**不虚构**；公开数据练习须标明「个人练习，非公司业务」。

**链接**：完整 `https://`；Boss/微信里**单独一行发链接**；首屏别太大，弱网少白屏。

---

## 页面与导航

- **首页**：一句定位（偏数据/AI 应用）+ **作品**主 CTA。  
- **作品**：列表 → 每项目独立 URL。  
- **关于**：教育、技能；**电话 / 微信 / 邮箱仅见简历 PDF**，网页不挂二维码、手机号或明文邮箱。  
- **简历**：PDF 一键下载（与投递版一致）；`robots.txt` + PDF 响应头降低搜索引擎收录，**不设验证码/登录**。  
- **多岗位（可选）**：`/pitch/*` 固定页，简历里写对应链接；不做访客切换身份。  

**私人内容**（投递记录、复盘等）不进本站；用语雀/Notion 等，或单独私有仓库。

---

## 作品怎么摆

**现状**：实习以招投标 Web 为主；分析向可视化还少。  
**目标**：让面试官看到「能分析 + 懂 AI 应用落地 + 能交付」。

| 类型 | 写法要点 |
|------|----------|
| **实习 Web** | 少只写页面：写筛选/统计/导出、字段与流程、权限与追溯；配脱敏截图、流程图。副线投开发时强调 Cursor/AI 辅助开发与模块职责。 |
| **数据分析练习** | 做 **1～2 个**完整小项目（公开数据）：问题 → 取数/清洗 → 分析 → 结论 → 局限；至少一组图/看板静态图即可。 |
| **测试/评测** | **不做**独立项目页；简历一句带过即可。 |

**每个项目页**：背景 → 你做了什么 → 结果（数字/图）→ 你的职责 → 素材（alt、打码）。

---

## 设计与技术

- **浅色** + 一个主色；标题/正文字体各一；首页可大图/色块，但「名字 + 作品」首屏内可见。  
- **Astro** 优先（内容站）；模板极简即可，Tailwind 可要可不要。  
- **第一期必须有**：响应式、项目列表/详情、导航、favicon、每页 title/description、简历 PDF、404 回首页。

---

## 第一期验收

- [ ] 手机首屏：身份 + 进作品路径清楚。  
- [ ] **至少 2 个项目页**（建议 1 实习 + 1 数据分析练习；练习带性质声明）。  
- [ ] 简历可打开；子路径刷新不 404。  
- [ ] 你能自己改 md、加一篇项目。

---

## 部署（一句）

托管 **Cloudflare Pages 或 Netlify**（连 GitHub）；域名可选（平台子域名也能写进简历）。图压缩；公网无未脱敏数据。

## 仓库目录

| 路径 | 用途 |
|------|------|
| `docs/` | 文档总索引见 `docs/README.md`（01 建站 → 02 面试 → 03 数据分析） |
| `data/` | 分析用 CSV，见 `data/README.md` |
| `content/drafts/` | 首页/关于草稿 |
| `content/projects/` | 项目 md |
| `content/pitch/` | 多岗位页（可选） |
| `assets/images/` | 截图、头像 |
| `assets/files/` | 简历 PDF |

有 Astro 工程后 md 可迁到工程约定目录，规则不变。

---

## 习惯

投递前：网站链接与简历 PDF **同一版本**。新项目别漏**性质标签**（实习 / 个人练习）。
