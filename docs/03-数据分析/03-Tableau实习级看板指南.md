## 2. 先建「计算字段」（分析岗常做）

**数据** 窗格空白处右键 → **创建计算字段**：

| 名称 | 公式 | 用途 |
|------|------|------|
| `点击率` | `SUM([result_clicks]) / SUM([search_count])` | KPI、着色 |
| `人均搜索` | `SUM([search_count]) / COUNTD([date])` | 可选 KPI |
| `高搜低点击标记` | `IF SUM([search_count]) >= 80 AND [点击率] < 0.55 THEN "高搜低点击" ELSE "正常" END` | 散点/表筛选（在 keyword 层级用） |

格式：`点击率` 右键 → **默认属性** → **数字格式** → **百分比**。

## 2.5 界面先认清楚（后面步骤都靠这个）

```
┌──────────── 顶部 ────────────────────────────────────────┐
│  列（Columns）   行（Rows）   筛选器   标记（Marks）        │
├──────── 左侧数据窗格 ────────┬──── 中间图表区 ────────────┤
│  维度（蓝色）                 │                            │
│  度量（绿色）                 │                            │
└──────────────────────────────┴──────────────────────────┘
```

| 中文 | 在哪 | 干什么 |
|------|------|--------|
| **列 / 行** | 图表正上方、左侧 | 拖字段决定横纵轴 |
| **标记** | 列/行下面一块，写「自动/文本/线/条」 | **颜色、大小、标签、工具提示** 都在这一排的按钮里 |
| **标签** | 标记卡片上，「颜色」「大小」旁边 | 控制图上显示的文字 |
| **筛选器** | 行下面，或右侧浮出的勾选框 | 筛数据；Top N 在「编辑筛选器→顶部」 |
| **排序** | 顶部工具栏：三根横条+箭头 | 点行轴后点 **降序** 图标 |

**药丸颜色**：蓝色=维度，绿色=度量。右键药丸 → 改 **总和/平均值**、**排序**、**双轴**。

### ① KPI_核心指标（推荐：4 个小格，不空）

**为什么现在会又怪又空？**  
4 个度量全在 **列** 上 → 仪表板拉宽后每格很宽，数字挤在右上角，下面大片空白。

**推荐改法：拆成 4 张迷你工作表，仪表板横着拼（最像正式看板）**

每张只做 **一个大数字 + 标题用工作表名**，步骤相同：

| 工作表名 | 拖到什么 | 聚合 |
|----------|----------|------|
| `KPI_访问量` | `Page Views` → **标记→文本** | 总和 |
| `KPI_搜索量` | `Search Count` → **标记→文本** | 总和 |
| `KPI_点击率` | `点击率` → **标记→文本** | （已是聚合） |
| `KPI_停留` | `Avg Stay Seconds` → **标记→文本** | **平均值** |

**每张图操作（以 KPI_访问量 为例）**

1. 新建工作表 → 命名 `KPI_访问量`
2. **行、列都空着**（不要拖维度/度量到行列）
3. 左侧 `Page Views` 拖到中间 **标记** 卡片的 **文本** 上
4. **标记** 类型 = **文本**
5. **右键数字** → **设置格式** → 字号 **28～36**、**粗体**
6. **格式** → **对齐** → 水平 **居中**、垂直 **居中**
7. **格式** → **线** → 工作表边框 → **无**（可选）
8. 菜单 **工作表** → **显示标题** 打开；标题改成 **访问量**（或右键标题 → **编辑标题**）

其余 3 张同样做，标题分别：搜索量、点击率、平均停留(秒)。

**仪表板里**：新建 **水平** 容器 → 把 4 张 KPI 拖进去 → 每个 **等宽** → 高度 **80～100px** 即可。

### ③ 趋势_访问与搜索（双轴）⭐ 你正在做

#### 目标长什么样

- **一张图**里：折线 = 访问量，柱子 = 搜索量，共用底部日期横轴  
- ❌ 不是上下两张分开的图（那是还没开双轴）

#### 第 1 步：日期放对（别只有 1～31）

你现在横轴若是 **1、2、3…31**，那是「每月第几天」，不是完整时间线。

1. **列** 上若有 `天(Date)`，先删掉
2. 从左侧拖 **`Date`** 到 **列**
3. 弹出菜单选 **天**（或 `Date` 药丸右键 → **更改日期级别** → **天**）
4. 横轴应显示 **2025-08-01、08-02…** 这类完整日期（约 120 个点）

#### 第 2 步：先放访问量（折线）

1. 拖 `Page Views` 到 **行** → **总和**
2. **标记** 选 **线**

#### 第 3 步：再放搜索量，并开「双轴」（关键）

1. 再拖 `Search Count` 到 **行**（放在 `Page Views` 药丸 **右侧**）
2. 此时可能变成 **上下两张图** —— 正常，下一步修
3. 看 **行**  shelf：应有两个绿色药丸 `总和(Page Views)` 和 `总和(Search Count)`
4. **右键点击第二个** `总和(Search Count)` 药丸（在 **行** 上，不是标记里）
5. 菜单里选 **双轴**（Dual Axis）

**开双轴成功后：**

- 上下两张图 **叠成一张**
- 图表 **右侧** 多出一根 Y 轴
- 左侧标记卡片出现两个标签页：`总和(Page Views)` / `总和(Search Count)`

#### 第 4 步：线 + 柱

1. 点标记 **总和(Page Views)** 页 → 类型选 **线**
2. 点标记 **总和(Search Count)** 页 → 类型选 **条**（柱形）

#### 第 5 步：同步轴在哪（你问的这个）

> **前提**：必须先完成第 3 步「双轴」。没双轴就 **没有** 同步轴菜单。

1. 双轴后，看图表 **最右边**，有一根 **右侧纵轴**（刻度对应 Search Count）
2. **右键点击这根右侧纵轴**（或轴旁的刻度数字、轴标题 `Search Count`）
3. 弹出菜单 → 选 **同步轴**（Synchronize Axis）

**若菜单里没有「同步轴」：**

| 情况 | 处理 |
|------|------|
| 还是上下两张图 | 没开双轴 → 回到第 3 步，右键 **行** 上第二个药丸 |
| 右键点在左侧轴 | 改右键 **右侧** 那根轴 |
| 有同步轴但柱子很扁 | **访问量** 和 **搜索量** 数量级差太多 → **不要同步**，保持双轴即可，面试完全 OK |
| 右键点在空白处 | 对准轴刻度或轴标题再点 |

**不同步也可以发布**：折线看访问趋势、柱子看搜索量，双 Y 轴是常规做法。

#### 第 4 步收尾

- 工作表命名：`趋势_访问与搜索`
- 可选：右键右轴 → **编辑轴** → 标题改成「搜索量」；左轴「访问量」

### ⑦ 关键词_搜索vs点击（散点）⭐ 面试重点

**目标**：找出 **搜索多、点击相对少** 的词（高搜低点击）。

1. **新建工作表** → `关键词_搜索vs点击`
2. **列**：`Search Count` → **总和**
3. **行**：`Result Clicks` → **总和**
4. **标记** 保持 **圆**（自动）
5. **详细信息**：拖 `Keyword` 到 **详细信息**（每个点=一个词；若没有点，检查是否漏了这步）
6. **颜色**：`Bounce Rate` → **平均值** 拖到 **颜色**（跳出高偏红，可选）
   - 或改用计算字段 **`点击率`** 拖到 **颜色**（绿高红低，和 Top15 一致）
7. **工具提示**：确保有 `Keyword`、`Search Count`、`Result Clicks`、`点击率`

**加参考线（帮助口述）**

**线 1 · 搜索量门槛**

1. **列** 轴（Search Count 横轴）**右键** → **添加参考线**
2. 选 **常量** → 填 `80`（或 `100`）→ 标签「高搜索门槛」→ 确定

**线 2 · 理想对角线（可选，进阶）**

1. 分析 → **创建计算字段** → 名称 `理想点击` → 公式 `SUM([Search Count]) * 0.55`（按全站点击率）
2. 拖到 **行** 作第二条线较复杂；**新手可跳过**，用参考线 + 口述即可

**怎么读图（背这个）**

```
点击
 ↑     ·  ·    ← 正常：搜索高、点击也高（靠近左上）
 |   ·
 |        · ·  ← 问题：搜索高、点击低（偏右下）
 └──────────→ 搜索
```

- **偏右下** 的点：搜得多、点得少 → 结果页/摘要/排序可能有问题  
- 举例：「开标记录」「电子招投标」类词

**面试一句**：「散点看搜索和点击是否匹配；偏离对角、落在右下的词进周报建议优化结果页。」

## 8. 常见坑（你对照过的）

| 现象 | 原因 | 怎么改 |
|------|------|--------|
| KPI 停留 50 万+ | 用了 **总和** 不是 **平均值** | `Avg Stay Seconds` 药丸 → 度量 → 平均值 |
| 关不了轴标题 | 在「格式」里只能改字体 | **右键图表底下刻度** → 编辑轴 → 标签/刻度线 → 无 |
| Top15 手勾 | 用了「常规」筛选 | 编辑筛选器 → **顶部** → 按字段 Top 15 |
| 趋势横轴只有 1～31 | 日期级别是「月内第几天」 | `Date` 拖到列 → 选 **天**（完整日期） |
| 上下两张趋势图 | 没开 **双轴** | **行** 上右键第二个度量药丸 → 双轴 |
| 找不到 **同步轴** | 没双轴，或右键点在左轴 | 先双轴，再 **右键右侧纵轴** |
| 同步后柱子看不见 | 两指标量纲差太大 | **取消同步**，双 Y 轴即可 |
| 颜色全蓝 | 没把 `点击率` 拖到 **标记→颜色** | 从数据窗格拖到标记的「颜色」按钮 |
