# Tableau · 用户套餐分析看板（详细步骤）

> **目的**：给「广电用户套餐与开通分析」补一块 **Tableau Public**，和简历里的 Tableau 对齐。  
> **数据**：仓库 `data/04-用户套餐分析/`（IBM Telco 公开集映射版）。  
> **网站页**：完成后把 Public 链接发我，挂到 `/projects/operator-user-analytics`。  
> **页脚声明（必加）**：*公开数据 IBM Telco Customer Churn，用于演示套餐合同与在网结构分析；非广电公司原始用户表。实习 3800+ 为内网数据，不外传。*

若 Tableau 还没装好，先看 [02-Tableau快速上手.md](02-Tableau快速上手.md)。  
招投标关键词那套看板步骤在 [03-Tableau实习级看板指南.md](03-Tableau实习级看板指南.md)，**和本篇不是同一份数据**。

## 0. 你要做出什么样子（验收标准）

做完后，仪表板上一眼能看到：

1. **顶部 KPI**：用户数、在网用户数、在网率、（可选）月付用户占比  
2. **套餐合同对比**：月付 / 一年 / 两年 的用户数 + 在网率  
3. **互联网业务结构**：光纤 / DSL / 未开通互联网  
4. **筛选器**：至少能按「套餐合同」或「互联网业务」筛  
5. **页脚声明**（上面那句）  
6. 发布到 **Tableau Public**，得到可分享链接  

面试一句话：

> 「用公开电信客户数据做了套餐合同与在网率看板；实习里用公司内网套餐/开通/地区表做同类分析。」

## 2. 导入数据（约 3 分钟）

1. 打开 **Tableau Desktop** 或 **Tableau Public**（免费版即可发布）。  
2. 连接 → **文本文件** → 选 `01-用户练习明细.csv`。  
3. 进入工作表后，在左侧数据窗格检查：  
   - `tenure_months`、`monthly_charges` 应为 **绿色度量**（数字）。  
   - 若变成蓝色维度：右键字段 → **更改为度量** → **数字**。  
   - `package_type`、`open_status`、`service_type` 保持 **蓝色维度**。  
4. （可选）数据源页把表显示名改成 `用户明细`，方便以后换数据源。

---

## 3. 先建计算字段（必做）

左侧数据窗格空白处右键 → **创建计算字段**：

| 名称 | 公式 | 用途 |
|------|------|------|
| `是否在网` | `IF [open_status] = "在网" THEN 1 ELSE 0 END` | 算在网人数 |
| `在网率` | `SUM([是否在网]) / COUNTD([customer_id])` | KPI、柱上标签 |
| `是否月付` | `IF [package_type] = "月付套餐" THEN 1 ELSE 0 END` | 可选 KPI |
| `月付占比` | `SUM([是否月付]) / COUNTD([customer_id])` | 可选 KPI |

格式：

- 右键 `在网率` → **默认属性** → **数字格式** → **百分比**（保留 1 位小数）。  
- 同样给 `月付占比` 设成百分比。

## 4. 界面别迷路（和招投标指南相同）

```
┌──────────── 顶部 ────────────────────────────────────────┐
│  列（Columns）   行（Rows）   筛选器   标记（Marks）        │
├──────── 左侧数据窗格 ────────┬──── 中间图表区 ────────────┤
│  维度（蓝色）                 │                            │
│  度量（绿色）                 │                            │
└──────────────────────────────┴──────────────────────────┘
```

| 中文 | 干什么 |
|------|--------|
| **列 / 行** | 决定横纵轴 |
| **标记** | 颜色、大小、标签、工具提示 |
| **筛选器** | 筛数据；可显示为右侧勾选 |

## 5. 做 6 张工作表（按顺序做）

每做完一张，底部工作表标签 **双击改名** 成下面的名字，方便拖仪表板。

---

### ① KPI_用户数

1. 新建工作表，命名 `KPI_用户数`。  
2. 把 `customer_id` 拖到 **标记 → 文本**。  
3. 右键该药丸 → **度量** → **计数（不同）**（COUNTD）。  
4. 标记选 **文本**；字号调大（标记卡片 → 文本 → … → 编辑 → 字号 18～24）。  
5. 标题改成：`用户数`（右键工作表标题 → 编辑标题）。

---

### ② KPI_在网用户

1. 新建 `KPI_在网用户`。  
2. 将 `是否在网` 拖到 **标记 → 文本**，聚合为 **总和**。  
3. 标题：`在网用户`。

---

### ③ KPI_在网率

1. 新建 `KPI_在网率`。  
2. 将 `在网率` 拖到 **标记 → 文本**。  
3. 确认显示为百分比。  
4. 标题：`在网率`。

---

### ④ 套餐合同_用户数与在网率

1. 新建 `套餐_结构`。  
2. **列**：拖入 `package_type`。  
3. **行**：拖入 `customer_id`（COUNTD）→ 得到各套餐用户数柱状图。  
4. 再把 `在网率` 拖到 **标记 → 标签**（或再做双轴，见下）。  
5. **颜色**：把 `package_type` 拖到颜色（可选）。  
6. 排序：点用户数轴 → 工具栏 **降序**。  

**想同时看用户数 + 在网率（推荐双轴）：**

1. **行** 上先放 `CNTD(customer_id)`，再放 `在网率`。  
2. 右键行上的 `在网率` → **双轴**。  
3. 右键右侧轴 → **同步轴**（若单位冲突不同步也行：左柱右折线）。  
4. 标记卡片里分别设置：左边用 **条形**，右边用 **线** 或 **圆**。  
5. 标题：`套餐合同：用户数与在网率`。

面试讲法：月付用户多、在网率往往更低（以你图上数字为准）。

---

### ⑤ 互联网业务_结构

1. 新建 `业务_结构`。  
2. **列**：`service_type`。  
3. **行**：`CNTD(customer_id)`。  
4. `在网率` → **标签**。  
5. 标题：`互联网业务类型分布`。  

说明：公开集没有中国「地区」字段，用业务类型做第二结构视图；地区以实习内网为准。

---

### ⑥ （可选加分）在网月数_分布

1. 新建 `tenure_分布`。  
2. 把 `tenure_months` 拖到 **列**（连续）。  
3. `CNTD(customer_id)` 到 **行** → 直方图。  
4. 或：`tenure_months` 右键 → **创建** → 创建组 / 用固定箱宽。  
5. **颜色**：`open_status`（在网 vs 已流失）。  
6. 标题：`在网月数分布（按是否在网着色）`。

---

## 6. 拼仪表板（约 10 分钟）

1. 底部 **新建仪表板**。  
2. 尺寸：选 **桌面浏览器**（或自定义宽 1000～1200）。  
3. 从左侧把工作表拖入：  

```
┌──────── KPI_用户数 ── KPI_在网用户 ── KPI_在网率 ─────────┐
├──────────────── 套餐_结构（大） ──────────────────────────┤
├──────────────── 业务_结构 ───────────────────────────────┤
├（可选）tenure_分布 ──────────────────────────────────────┤
└──────── 文本：页脚声明 ──────────────────────────────────┘
```

4. **添加文本对象**（左侧「对象」→ 文本）贴在底部，粘贴：

```text
公开数据：IBM Telco Customer Churn（约 7043 行）。
用于演示「套餐合同 / 在网 / 互联网业务」结构分析，非广电公司原始用户表。
实习中的 3800+ 条为内网用户业务数据，不外传。
```

5. **筛选器**（推荐）：  
   - 任意一张明细相关表打开 → 把 `package_type` 拖到筛选器 → 右键筛选器 → **应用到工作表** → **所选工作表**（勾选仪表板上的图）。  
   - 仪表板上显示筛选器：点图 → 右上角 ▼ → **筛选器** → 勾选 `package_type`。  
   - 同样可加 `service_type`。

6. 仪表板标题改成：`电信客户 · 套餐合同与在网结构（公开数据演示）`。

## 10. 常见坑

| 现象 | 处理 |
|------|------|
| `在网率` 显示成 0～1 小数 | 设百分比格式 |
| `customer_id` 变成求和 | 改成 **计数（不同）** |
| 中文乱码 | 用 `01-用户练习明细.csv`（UTF-8-BOM）；或数据源 → 字符集 UTF-8 |
| 想强调「开通」但公开集是流失 | 口述：公开集用「在网/已流失」对应留存结果；实习里是套餐/开通/地区口径 |
| 和招投标 Tableau 搞混 | 那是另一份关键词练习；本篇只服务用户套餐页 |
