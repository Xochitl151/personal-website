# BI 看板作品 · 怎么整（给 HR 用）

> HR 问 Tableau / Power BI / FineBI，本质就一件事：**有没有能点开或能截图的独立看板**。  
> **本站策略**：只做 Tableau；**Power BI / FineBI / 电商漏斗看板均不做。**

---

## 三个工具 · 作品长什么样

| 工具 | 独立作品通常指 | 怎么给 HR 看 | 难度 |
|------|----------------|--------------|------|
| **Tableau** | `.twbx` + **Tableau Public 链接** | 发链接，可嵌入作品集 | ⭐ 最适合先做 |
| **Power BI** | `.pbix` + 发布到 Web 或 **PDF/长截图** | 链接或 3～4 张截图 | ⭐⭐ |
| **FineBI** | 帆软里做的仪表板 | 多为内网；**脱敏截图 + 说明** 即可 | ⭐⭐⭐ 公网难 |

**结论**：  
- 简历写了 **Tableau** → 作品集以 Tableau Public 链接 + 截图为准（用户套餐 / 招投标关键词练习）。  
- Power BI / FineBI：**不做**；面试若被问，如实说主工具是 Tableau，其他可快速上手。

## 推荐：做几个、用什么数据

### 看板 1 · Tableau（必做）— 招投标 / 用户行为

**故事线**：和实习、网站项目 1 一致，HR 不打架。

**没有真实脱敏数据时**（二选一，诚实标注）：

| 方案 | 数据 | 页脚声明 |
|------|------|----------|
| **A 优先** | 向公司要 **脱敏汇总表**（按日关键词量、PV 即可） | 实习项目脱敏 |
| **B 练习** | `data/01-招投标搜索/02-实习级练习.csv`（5456 行） | 分析方法演示，非公司业务 |

**看板目标（实习级 · 见 `03-Tableau实习级看板指南.md`）**：

1. 4 个 KPI（访问量、搜索量、点击率、平均停留）  
2. 关键词 Top15 + 按点击率着色  
3. 访问/搜索双轴趋势  
4. 渠道结构 + 设备占比  
5. 地区×渠道热力  
6. 搜索 vs 点击散点（高搜低点击）  
7. 跳出率按渠道周趋势  
8. 全局筛选：日期、渠道、设备、地区

**交付**：Tableau Public 链接 + 2 张截图 → `assets/projects/01-bidding-analytics/screenshots/`
