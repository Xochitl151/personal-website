## 30 分钟流程（第一次）

### 0. 安装（10 分钟）

1. 打开 https://public.tableau.com/s/  
2. 注册账号（免费）  
3. 下载 **Tableau Public Desktop** 并安装  
4. 登录 Public 账号（发布看板必须）

### 1. 导入数据（2 分钟）

1. 打开 Tableau → **连接** → **文本文件**  
2. **简易入门**（10 分钟练手）：`data/01-招投标搜索/01-练习小样本.csv`  
3. **实习级看板**（面试用）：`data/01-招投标搜索/02-实习级练习.csv`（5456 行）→ 按 **`docs/03-数据分析/03-Tableau实习级看板指南.md`** 做 8 张图  
4. 点 **打开** → 拖到 **工作表**

### 2. 做 4 块（15 分钟 · 仅练手）

| 块 | 怎么拖 |
|----|--------|
| KPI | 新建工作表：把 `page_views` 拖 **文本**，右键 → 度量 → **总和**；再复制改 `search_count`、`avg_stay_seconds`（停留可用 **平均值**） |
| 关键词 Top10 | 行：`keyword`；列：`search_count` 总和；排序降序；筛选 Top 10 |
| 趋势 | 列：`date`（天）；行：`page_views` 总和 |
| 筛选 | 把 `channel` 拖到 **筛选器** |

### 3. 拼仪表板 + 发布（5 分钟）

1. 新建 **仪表板**，把上面 3 张图拖进去  
2. **文件 → 另存为到 Tableau Public** → 等上传  
3. 复制浏览器里的 **链接** 发我

## 常见问题

**Q：Public 和数据会公开吗？**  
A：发布到 Public 的看板网上可见。练习 CSV 是假数据没问题；**真实业务数据不要发 Public**，只做脱敏汇总或只用截图不上传敏感数据。

**Q：和实习说的 Tableau 对得上吗？**  
A：练习看板证明 **会工具**；口述实习经历 + 练习看板 **方法论一致**。有脱敏真数据后再替换数据源最稳。

**Q：Tableau 比 Power BI 老吗？**  
A：公司选型不同，不是「老工具」。应届 **有一个 Public 链接** 比争论新旧有用。

## 仪表板筛选器（以后常用 · 别用双击「添加筛选器」）

「添加筛选器」点不动 / 拖不动时，用下面 **方法 A**（最稳）。

### 方法 A：从单张图里显示（推荐）

1. 打开任意一张工作表（如 **关键词Top10**）  
2. 把 **`channel`** 拖到 **「筛选器」** → 勾选 **全部** → 确定  
3. **右键** 筛选器里的 **`channel`** → **「显示筛选器」**  
4. 回到 **仪表板**  
5. 点 **某张图右上角 ▼**（或点中图再点 ▼）→ **筛选器** → **`channel`** → **在仪表板上显示**  

页面上会出现渠道勾选框，并可勾选 **作用于哪些工作表**。

### 方法 B：多张图一起筛

在方法 A 第 3 步之后：

- **`channel` 右键** → **应用于工作表** → **使用此数据源的所有项**

### 避免

- **不要双击**「添加筛选器」（容易出现空白浮动框）  
- 白框出现：选中 → **Delete** 删除  

### 现在

看板已有 **渠道对比** 图，**可先发布**；筛选器下次按方法 A 加一次就会了。
